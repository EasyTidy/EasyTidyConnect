# M2 实现记录

> 2026-11-15

## 已完成

### EasyTidy 本地 Bridge

EasyTidyPro 新增 `ConnectBridgeServer`：

- 只监听 `127.0.0.1:53401`（端口冲突自动 +1~+3）；
- Bearer token，首次启动自动生成并写入 `ConnectBridge` 配置；
- 同时写 `connect-bridge.json` 到 EasyTidy 配置目录：
  ```json
  { "app": "EasyTidyPro", "url": "http://127.0.0.1:53401", "token": "…", "port": 53401, "version": "2.0.4.1024" }
  ```
- 接口：
  - `GET /api/connect/v1/health`
  - `GET /api/connect/v1/tasks`
  - `GET /api/connect/v1/workflows`
  - `POST /api/connect/v1/tasks/{id}/run`
  - `POST /api/connect/v1/workflows/{id}/run`
  - `GET /api/connect/v1/runs/{runId}`
- 运行状态保存在内存（进程重启清空）。

### Connect 侧

- 设置页新增 Bridge 地址/token、测试连接、“从 EasyTidy 导入”；
- 启动时若未配置 Bridge，自动读取 `connect-bridge.json`；
- 触发器新增动作：
  - `easytidy_task`：选择 EasyTidy 任务；
  - `easytidy_workflow`：选择 EasyTidy 工作流；
- NFC 触发后调用 Bridge，结果页显示“已提交 EasyTidy 任务/工作流，运行 ID …”；
- Connect 每 2 秒轮询 Bridge 运行状态，最多 10 分钟，成功/失败写回运行历史；
- 运行历史页每 3 秒自动刷新，显示 EasyTidy 运行 ID。

### 三种启动模式

- 未配置 Bridge：只显示独立版“开机启动”开关；
- 配置 Bridge 后显示：
  - 跟随 EasyTidy；
  - 独立开机启动；
  - 仅手动；
- 跟随模式支持启动参数：
  ```text
  EasyTidyConnect.exe --embedded --minimized --parent-pid <pid>
  ```
- `--parent-pid` 监视父进程，父进程退出后 3 秒内退出；
- 支持 `--bridge-url` 与 `--bridge-token-file`，避免 token 出现在命令行；
- 设置页切换模式会同步启用/禁用系统自启；
- EasyTidy 集成卡片支持“打开界面”：已运行时通过单实例唤起窗口，未运行时启动 Connect。
