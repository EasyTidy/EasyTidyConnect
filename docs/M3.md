# M3 实现记录

> 2026-11-15

## 已完成

### 纪念日工作室

- 项目 CRUD：名称、日期、标题、收件人、开场、正文、结尾、主题色、模板、自定义 CSS；
- 5 套内置模板：
  - `minimal` 极简
  - `polaroid` 拍立得
  - `letter` 信纸
  - `timeline` 时间轴
  - `starry` 星空
- 照片上传（base64 → 本地文件），单张 ≤ 12 MB；
- 本地预览：`GET /a/{slug}`，照片 `GET /a/{slug}/photos/{file}`；
- 发布版本记录 `anniversary_versions`。

### AI 文案

- Provider 管理：名称、类型、Base URL、模型、API Key、默认项；
- 支持：
  - OpenAI 兼容（OpenAI/DeepSeek/OpenRouter/自建网关）；
  - Anthropic Messages；
  - Google Gemini generateContent；
- 结构化输出：

```json
{ "title": "", "opening": "", "body": "", "closing": "" }
```

- 解析失败时回退提取 JSON 对象；错误显示在 UI。

### 发布

- S3 / MinIO / Cloudflare R2（S3 兼容）：
  - AWS Signature V4；
  - 路径风格 `endpoint/bucket/key`；
  - HTML + 照片上传；
  - 发布版本写库；
  - 公开 URL 可配置 `public_base_url`。
- 局域网穿透 / Cloudflare Tunnel：
  - `lan_tunnel`：cloudflared Quick Tunnel，随机 `trycloudflare.com`；
  - `cloudflare_tunnel`：Named Tunnel + token + hostname；
  - 只暴露公开预览端口 `127.0.0.1:53410` 的 `/a/*`；
  - `/t`、`/w` 不通过隧道暴露；
  - 发布时直接返回隧道 URL。
- Cloudflare Pages Direct Upload：
  - BLAKE3 资源哈希（base64 + 扩展名，取前 32 hex）；
  - upload JWT / check-missing / assets upload / upsert；
  - deployment manifest；
  - 轮询 `file_count`；
  - 支持自定义域名。

### NFC 动作

- 新增 `publish_anniversary`：
  - 选择纪念日项目；
  - 选择发布目标；
  - 碰标签后渲染并上传，返回发布 URL。
