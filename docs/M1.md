# M1 实现记录

> 2026-11-15

## 已完成

### 核心

- SQLite 数据库与迁移式建表（triggers / runs / settings）；
- 触发器 CRUD、启停、删除；
- 动作：
  - `message`：测试消息；
  - `webhook`：POST JSON 到配置 URL；
  - `open_url`：返回待打开 URL 文案；
  - `easytidy`：占位，返回“未连接”；
- 每次触发写 `runs`，记录 running/success/failed、来源、错误；
- 第一次成功触发自动写入 `verified_at`。

### NFC

- 每个触发器生成：
  - `/t/{publicId}?k={token}` 触发 URI；
  - `/w/{writeToken}` 手机写入辅助页；
  - 前端二维码；
- 写入辅助页显示 URI、字节数、复制按钮；
- 手动机记“已写入”；当前不集成桌面读卡器。

### 桌面壳

- Tauri 2 + React 19；
- 单实例：重复启动只唤醒已有窗口；
- 托盘：关闭窗口隐藏，服务继续；托盘菜单“打开 / 退出”；
- 开机启动：设置页开关通过 `tauri-plugin-autostart` 写入/移除系统自启项；
- 设置持久化：设备名、端口、开机启动；
- 修改端口需重启应用（当前不做热切换监听）。

### 发布

- `npm run tauri build` 生成 Windows NSIS/MSI；
- GitHub Actions `.github/workflows/release.yml`：打 `v*` tag 构建三平台 Release。

## 验证

- `npm run build` 通过；
- `cargo check` 通过；
- `cargo test -p connect-core`：2 passed；
- Release 应用 `/health` 正常；
- `/t` 触发成功，`/w` 写入页正常，错误 token 返回 401；
- 关闭窗口后进程仍在、`/health` 仍可访问；
- 第二次启动不新增进程（单实例）。

## 已知限制

- 修改端口后需要重启应用；
- 触发 URL 依赖当前局域网 IP，IP 变化需重写标签；
- `open_url` 当前在结果页显示 URL，不做 302；
- `easytidy` 动作是占位。
