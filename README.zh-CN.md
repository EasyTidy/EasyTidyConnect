# EasyTidy Connect

[English](README.md) | **中文**

碰一下 NFC 标签，让一件事发生。

EasyTidy Connect 是一款桌面应用，把普通的 NFC 贴纸变成按钮。用手机碰一下标签，就能弹出一条消息、打开网页、运行 EasyTidy 任务，或打开一张你亲手制作的纪念日贺卡。

它可以单独使用，也可以搭配 [EasyTidy](https://github.com/EasyTidy)，碰一下就整理文件。

## 功能

**仪表盘**：一眼看到应用是否就绪、启用了几个触发器、最近运行了什么。新手指引带你完成第一张标签。

**触发器**：一个触发器 = 一张标签 + 一个动作。可以选择碰一下之后：

- 显示测试消息，验证标签能否使用
- 打开网页
- 通知其他服务
- 运行 EasyTidy 任务或工作流
- 打开纪念日贺卡

触发器可以随时启用、停用和编辑，并能看到哪些标签已写入、已验证可用。

**标签**：用手机写入标签需要的东西都在这里：可复制的链接、可扫描的二维码，以及分步骤的写入辅助页。第一次碰标签成功后，自动标记为“已验证”。

**纪念日工作室**：做一张碰一下就能打开的贺卡。

- 填写标题、开场、正文和结尾，或者给出几个关键词、选好语气，让 AI 帮你写。
- 10 套设计可选：极简、拍立得照片墙、复古信纸、时间线、星空、红金喜帖、森系拱门、杂志封面、派对门票、胶片相册。
- 用自己的话描述想要的风格，让 AI 设计一套专属模板，还能继续调整。
- 添加照片、背景音乐和视频。拖动调整顺序，选择封面并裁剪到合适的样子。
- 实时预览对方在手机上看到的效果。
- 发布到网上，在哪里都能打开；或者只在家里的 Wi-Fi 下使用。
- 把贺卡地址写进标签，或分享到微信、微博等应用，并自定义分享卡片。

**运行历史**：最近 50 次触发记录，包括时间、结果和错误信息。

**设置**：浅色/深色模式、界面风格、设备名、开机启动，以及与 EasyTidy 的连接。连接 EasyTidy 后，可以让 Connect 跟随 EasyTidy 一起启动和退出。

关闭窗口后应用会留在系统托盘继续运行，标签随时可用。

## 快速上手

1. 从 [Releases](https://github.com/EasyTidy/EasyTidyConnect/releases) 下载安装包并安装。
2. 准备一张 NFC 贴纸（见 [NFC 标签](#nfc-标签)），并在手机上安装 NFC 写入 App，例如 NFC Tools。
3. 在「触发器」页新建一个“测试消息”触发器。
4. 打开「标签」页，用手机扫二维码，复制链接并写入贴纸。
5. 碰一下贴纸，手机会打开结果页。

除非触发器打开的是已发布到网上的贺卡，手机需要和电脑连在同一个 Wi-Fi 下。

制作纪念日贺卡：打开「纪念日」，填写内容、选择设计、添加照片，然后点「保存并发布」和「写入 NFC」。

## NFC 标签

只要你的手机能读写，任何 NFC 标签都可以使用。标签能不能用，只取决于手机。

常见的 NTAG213、NTAG215、NTAG216 贴纸在 iPhone 和安卓手机上都能读写。它们很便宜，批量购买时一张通常不到一元。

标签里只存一个短链接。写入前，应用会显示这个链接占用多少字节，请确认你的标签容量不小于这个数值：

| 标签 | 容量 |
|---|---|
| NTAG213 | 144 字节 |
| NTAG215 | 504 字节 |
| NTAG216 | 888 字节 |

安卓手机请先在系统设置里打开 NFC。

## 开发

环境要求：[Node.js](https://nodejs.org/) 22+、[Rust](https://rustup.rs/)（stable），以及对应系统的 [Tauri 依赖](https://tauri.app/start/prerequisites/)。

```bash
npm install          # 安装依赖
npm run tauri dev    # 开发模式运行
npm run tauri build  # 打包安装程序，输出到 target/release/bundle/
cargo test           # 运行 Rust 测试
```
